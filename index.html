Module 11

Text → audio

Pick a saved book for instant audio, or paste any text to have it read aloud.
Why does it still sound American?
Voice availability is controlled entirely by your Windows machine, not by this app — I can pick the best-matching installed voice, but I can't install a voice that isn't there. To add real Hindi/Gujarati voices: open Windows Settings → Time & Language → Language & region → Add a language, add Hindi or Gujarati, open that language's options and download its Speech pack. Once installed, restart Chrome — the new voice will show up below.
